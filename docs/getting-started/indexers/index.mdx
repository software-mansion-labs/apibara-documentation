# Building indexers

Indexers are created using the `defineIndexer` higher-order function. This function takes a _stream definition_ and returns a function to define the indexer.

The job of an indexer is to stream and process historical data (backfilling) and then switch to real-time mode. Indexers built using our SDK are designed to handle chain-reorganizations automatically.
If, for any reason, you need to receive notifications about reorgs, you can define [a custom `message:invalidate` hook](/docs/getting-started/plugins#inline-hooks) to handle them.

By default, the indexer is stateless (restarts from the beginning on restart) and does not provide any storage. You can add persistence and storage by using one of the provided storage plugins.

### Examples

The following example shows how to create a Starknet indexer.

```ts [starknet.indexer.ts]
import { StarknetStream } from "@apibara/starknet";
import { defineIndexer } from "apibara/indexer";

export default defineIndexer(StarknetStream)({
  /* ... */
});
```

## With runtime config

To configure the indexer at runtime, export a function that takes the configuration and returns the indexer's definition.

```ts
import { StarknetStream } from "@apibara/starknet";
import type { ApibaraRuntimeConfig } from "apibara/types";
import { defineIndexer } from "apibara/indexer";

export default function (runtimeConfig: ApibaraRuntimeConfig) {
  return defineIndexer(StarknetStream)({
    // ...
  });
}
```

## Indexer configuration

All indexers take the same configuration options.

- **`streamUrl`**<span class="arg-type">`string`</span><br/><span class="arg-description">The URL of the DNA stream to connect to.</span>
- **`clientOptions`**<span class="arg-type">`CreateClientOptions`</span><br/><span class="arg-description">Optional gRPC client settings, including credentials, channel options, and default call options. Import the type from `@apibara/protocol`.</span>
- **`filter`**<span class="arg-type">`TFilter`</span><br/><span class="arg-description">The filter to apply to the DNA stream. See the [Starknet filter reference](/docs/starknet/filter) for the available options.</span>
- **`finality`**<span class="arg-type">`"finalized" | "accepted" | "pending"`</span><br/><span class="arg-description">Receive data with the specified finality. Defaults to `accepted`. Note that the `finality` argument passed to `transform` and `factory` can also be `"unknown"`.</span>
- **`startingBlock`**<span class="arg-type">`bigint`</span><br/><span class="arg-description">The first block to index, inclusive. Defaults to the genesis block when neither starting option is supplied. Use this or `startingCursor`, not both.</span>
- **`startingCursor`**<span class="arg-type">`Cursor`</span><br/><span class="arg-description">Resume after this cursor. `orderKey` is the block number and the optional `uniqueKey` is its hash, which allows the server to detect an offline reorganization. Import `Cursor` from `@apibara/protocol`.</span>
- **`debug`**<span class="arg-type">`boolean`</span><br/><span class="arg-description">Enable debug mode. This will print debug information to the console.</span>
- **`transform`**<span class="arg-type">`({ block, cursor, endCursor, finality, production, context, abortSignal }) => Promise<void>`</span><br/><span class="arg-description">The transform function called for each block received from the DNA stream.</span>
- **`factory`**<span class="arg-type">`({ block, cursor, endCursor, finality, production, context, abortSignal }) => Promise<{ filter?: TFilter }>`</span><br/><span class="arg-description">The factory function used to add data filters at runtime. Useful for creating indexers for Starknet factory contracts. It receives the same arguments as `transform`.</span>
- **`hooks`**<span class="arg-type">`object`</span><br/><span class="arg-description">The hooks to register with the indexer. Refer to the [plugins & hooks](/docs/getting-started/plugins) page for more information.</span>
- **`plugins`**<span class="arg-type">`array`</span><br/><span class="arg-description">The plugins to register with the indexer. Refer to the [plugins & hooks](/docs/getting-started/plugins) page for more information.</span>

### The transform function

The `transform` function is invoked for each block received from the DNA stream. This function is where you should implement your business logic.

**Arguments**

- **`block`**<span class="arg-type">`TBlock`</span><br/><span class="arg-description">The block received from the DNA stream. See the [Starknet data reference](/docs/starknet/data).</span>
- **`cursor`**<span class="arg-type">`Cursor | undefined`</span><br/><span class="arg-description">The cursor preceding the received block. It can be absent at the start of the stream.</span>
- **`endCursor`**<span class="arg-type">`Cursor | undefined`</span><br/><span class="arg-description">The cursor of the current block.</span>
- **`finality`**<span class="arg-type">`"finalized" | "accepted" | "pending" | "unknown"`</span><br/><span class="arg-description">The finality of the block. Unlike the `finality` configuration option, this value can be `"unknown"`.</span>
- **`context`**<span class="arg-type">`object`</span><br/><span class="arg-description">The context shared between the indexer and the plugins.</span>
- **`production`**<span class="arg-type">`"backfill" | "live" | "unknown"`</span><br/><span class="arg-description">Whether the block was received while backfilling or following the chain's head.</span>
- **`abortSignal`**<span class="arg-type">`AbortSignal | undefined`</span><br/><span class="arg-description">The cancellation signal for the current run.</span>

The following example shows a minimal indexer that streams block headers and prints them to the console.

```ts [starknet.indexer.ts]
import { StarknetStream } from "@apibara/starknet";
import { defineIndexer } from "apibara/indexer";

export default defineIndexer(StarknetStream)({
  streamUrl: "https://mainnet.starkstream.io",
  filter: {
    header: "always",
  },
  async transform({ block }) {
    const { header } = block;
    console.log(header);
  },
});
```

### The factory function

The `factory` function adds data filters at runtime. Use it to track Starknet factory contracts that deploy other contracts.

**Arguments**

The `factory` function receives the same arguments as the [transform function](#the-transform-function).

- **`block`**<span class="arg-type">`TBlock`</span><br/><span class="arg-description">The block received from the DNA stream, matched by the factory filter. See the [Starknet data reference](/docs/starknet/data).</span>
- **`cursor`**<span class="arg-type">`Cursor | undefined`</span><br/><span class="arg-description">Same as for `transform`.</span>
- **`endCursor`**<span class="arg-type">`Cursor | undefined`</span><br/><span class="arg-description">Same as for `transform`.</span>
- **`finality`**<span class="arg-type">`"finalized" | "accepted" | "pending" | "unknown"`</span><br/><span class="arg-description">Same as for `transform`.</span>
- **`context`**<span class="arg-type">`object`</span><br/><span class="arg-description">The context shared between the indexer and the plugins.</span>
- **`production`**<span class="arg-type">`"backfill" | "live" | "unknown"`</span><br/><span class="arg-description">Same as for `transform`.</span>
- **`abortSignal`**<span class="arg-type">`AbortSignal | undefined`</span><br/><span class="arg-description">Same as for `transform`.</span>

The following example outlines an indexer that streams `PairCreated` events from a Starknet factory to detect new pools, and then streams the pools' events. Fill in the factory filter and decode the new pool addresses using your factory contract's ABI. Return event filters for those pools under `filter.events`.

```ts [starknet-factory.indexer.ts]
import { StarknetStream } from "@apibara/starknet";
import { defineIndexer } from "apibara/indexer";

export default defineIndexer(StarknetStream)({
  streamUrl: "https://mainnet.starkstream.io",
  filter: {
    events: [
      {
        // Match PairCreated events from your factory contract.
        /* ... */
      },
    ],
  },
  async factory({ block }) {
    const { events } = block;
    return {
      filter: {
        events: [
          /* ... filters for pool addresses decoded from events ... */
        ],
      },
    };
  },
  async transform({ block }) {
    const { header, events } = block;
    console.log(header);
    console.log(events);
  },
});
```
